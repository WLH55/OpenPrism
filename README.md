# OpenPrism

> 一个你，折射出生活的每一个维度。

OpenPrism 是一个**个人智能工作台**：与智能体对话，随手记录；数据自动沉淀为各个生活维度的统计面板，并打通你的笔记、AI 工具与各类平台资源。

## 定位

- **不是**又一个待办清单或笔记软件，而是一个以 Agent 为交互入口的个人数据中枢
- 一次输入（对话、记录、自动采集）→ 多维视图（面板）→ 洞察与行动
- 基于 [DeepSeek Harness (dsh)](https://github.com/deepseek-ai/deepseek-harness) 的插件架构搭建：UI、工具、模型、存储皆可插拔

## 六大维度面板

| 维度 | 示例内容 |
|---|---|
| 🌱 生活 | 习惯打卡、健康、日程、时间分配 |
| 💼 工作 | 项目进度、会议纪要、OKR 追踪 |
| 🏠 家庭 | 家庭事项、纪念日、成员动态 |
| 💰 理财 | 收支记录、资产配置、预算告警 |
| 📚 学习 | 阅读笔记、课程进度、知识沉淀 |
| ❤️ 情感 | 情绪日记、心情趋势、复盘 |

## 架构规划

```
openprism/
├── panels/        # 维度面板插件（UI，渲染图表与统计）
├── collectors/    # 数据采集器（从对话流提取结构化数据、抓取平台数据）
├── connectors/    # 平台连接器（笔记账号、AI 工具、各类 API）
├── agents/        # 智能体定义（生活助手、理财顾问、学习伙伴…）
└── storage/       # 个人数据层（本地优先，自主可控）
```

核心设计原则：

1. **本地优先**：个人数据存在自己控制的存储里，不依赖任何平台的内部格式
2. **一切皆插件**：面板、采集器、连接器都是独立的 dsh 插件，可单独增删
3. **对话即录入**：append-only 会话日志是数据源头，采集器负责从中提取结构化信息
