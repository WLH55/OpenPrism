## 1. 目标

把 `web/` 前端按 `prototype/index.html` 的信息架构与视觉语言重施工。**逻辑零改动**（API 调用、SSE、状态机原样保留），只换壳子和视图层。

## 2. 方案决定

- **引入 Tailwind v3（devDep）**：原型即 Tailwind 写就（token 经 CSS 变量映射），按原配置接入可 1:1 复刻间距/圆角/hover 细节；仅构建期工具，不违反服务端零运行时依赖铁律。
- `theme.css` 保留 token + 热力图分级等少量自定义类；其余样式随 Tailwind 类名走。
- 图标：从原型抄内联 SVG，集中到 `icons.tsx`。

## 4. 与原型的有意差异（数据层约束，非视觉偷懒）

| 原型 | 实现 | 原因 |
|---|---|---|
| 今日支出 ¥46 | 今日笔数 | 混合单位分类无统一货币语义（零预设） |
| 流水行 emoji（🍜☕🏃） | 分类色点 | 分类用户自定义，无法预映射 emoji |
| 伙伴卡「3 个会话/活跃/闲置」徽章 | 创建时间/绑定数 | 会话计数与活跃态无 API |
| 完成率分类明细（学习 3/4） | 总完成率 | 计划无分类字段 |
| 环比 ¥/h/次 单位 | 笔数 | 同「今日支出」 |
| 盘面汇总卡（累计时长等） | 周期笔数/合计/连续天数 | categoryView 可确定性折叠出的三值 |
