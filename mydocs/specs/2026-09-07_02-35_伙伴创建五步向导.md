## 模块与签名

`src/app/agents.ts` 扩展：

```ts
export interface AgentIdentity {
  description: string; emoji: string; color: string; avatar?: string; language: string; modelProviderId?: string;
}
create(uid, input: { name?: string; persona: string } & Partial<AgentIdentity> & { binding?: AgentBinding })
  // name 显式优先，空则 extractAgentName(persona) 兜底 "助手"
updateIdentity(uid, aid, patch: Partial<AgentIdentity>): void      // avatar 校验：^data:image\/(png|jpeg|webp|gif|svg\+xml);base64, 且 ≤200_000 字符；language ∈ {'','zh','en'}；color /^#[0-9a-fA-F]{6}$/
snapshotSync → { name, persona, binding, identity }
```

`src/app/persona.ts` 扩展：

```ts
ComposePromptInput += { identity?: { name; description; language } }
// 拼装顺序：身份块（有 agent 时）→ 灵魂(persona) → 日期 → 记忆 → 纪律 → 语言指令（末尾）
// 语言指令：zh → "无论用户用什么语言，请始终使用简体中文回复。"
//          en → "Always reply in English regardless of the user's language."
//          '' → 不加指令（跟随用户消息语言）
```

`src/app/conversations.ts`：

- systemPrompt 传入 current agent 的 identity（name/description/language）。

灵魂预置模板（`src/app/soul-templates.ts` 新增，中文，5 个）：`陪伴聊天`、`学习导师`、`健身教练`、`记账管家`、`编程助手`；每个为 `# 名字 + ## 语气 / ## 我怎么帮你 / ## 边界` 结构的 markdown（供向导一键选用后可改）。

## server 路由

```
POST /api/agents                 body 扩展：name/description/emoji/color/avatar/language/modelProviderId/binding
GET  /api/agents                 列表返回新字段（avatar 原样返回，≤200KB 可接受）
GET  /api/agents/:id             详情含 persona + identity
PUT  /api/agents/:id/identity    → updateIdentity（校验同上）
PUT  /api/agents/:id/persona     既有；名字推导改为：identity 有显式 name 列时不覆盖
PUT  /api/agents/:id/binding     既有
```
