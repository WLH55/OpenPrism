## §1 Requirements

- 用户在提醒页「新建任务 → 调度」里能选「单次」，指定**年月日 + 时分秒**（本地时区），到点只触发一次（错过 <24h 补跑，≥24h 跳过留痕——沿用 D6.3）。
- 单次时刻必须晚于当前时间（过去了的时刻创建无意义，拦住并提示）。
- 到点注入的触发说明、记忆提取用的规则描述、任务列表展示，都要把秒级时刻显示准确（秒非零时补 `:ss`，整分保持 `HH:mm` 不变——不破坏既有口径）。
- 任务列表里单次任务单独分组展示（「周期任务」组语义不对）。

## §2 Research Findings

- **后端已就绪，零改动面**：`TaskTrigger` 已含 `{kind:"once"; at:number}`（epoch 毫秒，秒级精度天然支持；tasks.ts:9）；`nextDue` 原样返回 at；调度器 `tick()` 已处理「跑过即跳」（`due <= anchor` continue，tasks.ts:479）与补跑窗口；`validateTrigger` 校验 at 有限；补跑/跳过留痕走既有 task_runs。
- **透传链路通**：server 路由把 trigger JSON 原样交 `TaskStore.create/update`（server.ts:1011）；模型工具 `create_task` 已支持 once（tasks.ts:527）；web `TaskTriggerLoose.kind` 联合类型已含 once（api.ts:316）；前端 `triggerText` 已能显示 once。
- **缺口 1（入口）**：`SCHEDULE_TYPES` 六个预设（每小时/每天/每工作日/每周/每月/自定义）全是周期类（Tasks.tsx:22-29），`create()` 无 once 分支——这就是用户看到「都是周期循环」的原因。
- **缺口 2（秒级显示）**：`formatLocal` 只到分钟（tasks.ts:217-221）；`describeTrigger` once → `单次 YYYY-MM-DD HH:mm`（tasks.ts:227）；`taskTriggerMessage` 的计划/触发时刻同源 formatLocal。秒非零的时刻会被四舍五入到分显示，注入模型的上下文不准确。
- **缺口 3（分组）**：列表按 daily / 其余 / 停用三分组，once 落进「周期任务」；`triggerShort` 对 once 显示「—」。
- UI 控件选型：日期用 `<input type="date">`（页面内 customEndDate 已有同款先例）、时/分/秒用 select 滚轮（既有 HOURS/MINUTES 模式加 SECONDS）——避开 datetime-local 在 iOS Safari 的兼容坑，与现有控件习惯一致。

## §4 Plan

### §4.1 File Changes

**1. `src/app/tasks.ts`**
- `formatLocal(ts, tz)`：秒非零（`ts % 60000 !== 0`）时在末尾补 `:ss`；整分输出不变（describeTrigger、taskTriggerMessage 计划/触发时刻自动受益）。
- `describeTrigger` once 分支无需另改（走 formatLocal）。

**2. `web/src/pages/Tasks.tsx`**
- `SCHEDULE_TYPES` 增加 `{ value: "once", label: "单次" }`（放「自定义」前）。
- 新增状态：`onceDate`（string，默认明天）、`onceHour/onceMinute/onceSecond`（number，默认 09:00:00）。
- 调度区 `schedKind === "once"` 时渲染：`<input type="date">` + 时/分/秒三个 select（SECONDS = 0..59）。
- `create()` 加 once 分支：`at = new Date(\`${onceDate}T${hh}:${mm}:${ss}\`).getTime()`；`onceDate === ""` 或 `!Number.isFinite(at)` 或 `at <= Date.now()` → setMessage 提示，不提交；合法则 `trigger = { kind: "once", at }`。
- `scheduleSummary` 加 once 分支：`单次 ${onceDate} ${hh}:${mm}:${ss}`（整分秒可省略 ss？统一显示 HH:mm:ss，明确无歧义）。
- 列表分组：新增「单次任务」section（enabled 且 kind==="once"），排在每日之后、周期之前；`recurring` 过滤排除 once。
- `triggerShort` once：显示 `M/D HH:mm`（秒非零补 `:ss`），从 `at` 按本地解析。

**3. `test/app-tasks.test.ts`**
- `describeTrigger` 用例追加：once 秒非零 → `单次 2026-09-03 08:00:30`；既有整分用例（`单次 2026-09-03 08:00`）继续通过即守护了不破坏。
