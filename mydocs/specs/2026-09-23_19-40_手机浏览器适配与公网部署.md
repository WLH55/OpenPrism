## 1. Requirements (Context)

- **Goal**: 手机（安卓，自带浏览器）打开 `http://<服务器地址>:8787` 后，登录、对话、发图片、看今天/盘面/成长、看提醒、改配置都能顺畅完成；打开长对话不必等全量事件下载；主屏幕能建一个图标快捷方式；这台服务器把 8787 端口映射到公网后，别人拿到会话 id 也读不到你的聊天记录。
- **In-Scope**:
  - 窄屏（< 768 像素）布局重排：侧栏 240 像素改抽屉、底部五项标签栏（对话 / 今天 / 盘面 / 成长 / 更多）、聊天头部收纳、卡片网格降列、附件入口拆成相册与拍照两个。
  - 视口高度与安全区：根容器改用 `100dvh`，输入区与底部标签栏加安全区内边距，避免地址栏收放与手势条遮挡。
  - 会话事件分段加载：接口加 `before` 与 `limit` 参数，前端初始取最近 50 条、触顶续取，且续取后不跳动滚动位置。
  - 应用清单与图标：`manifest.webmanifest`、Prism 图形生成的 192 与 512 图标、`theme-color`、`apple-touch-icon`、安装与快捷方式的启动范围。
  - 越权修复：`GET /api/conversations/:cid/events` 校验会话归属，非本会话返回 404。
  - 静态资源压缩与缓存头：`/assets/` 下按文件名哈希的资源带长缓存，`index.html` 不缓存；`text/*` 与 `application/javascript` 启用 gzip。
  - 部署文档：环境变量、监听地址、防火墙与端口映射、手机接入步骤、备份、公网暴露的风险告知与可选硬化。
- **Out-of-Scope**:
  - HTTPS 与证书（本次按明文 HTTP 使用；Cookie 的 `Secure` 属性同步留白，理由是置上以后明文 HTTP 下浏览器不再回传会话 Cookie，登录会直接失效）。
  - Service Worker 与离线缓存（浏览器对 `http://` 非本机来源不提供安全上下文，注册会被拒；写进清单只能得到主屏幕快捷方式，页面仍由浏览器加载）。
  - 原生安卓应用方向（`docs/design/2026-09-mobile-app.md` 与 `docs/dev-android.md` 属另一条线，本次不动）。
  - 消息列表虚拟滚动（分段加载把同时挂载的节点数控在合理规模，暂不引入虚拟列表库）。
  - 桌面端布局改动（≥ 768 像素的排版保持现状，仅新增缓存头与压缩这类无视觉影响的部分）。
- **Acceptance Criteria**:
  - [ ] AC1 窄屏（375×667 与 390×844 两种视口）下根容器宽度无横向溢出，`document.documentElement.scrollWidth` 不超过视口宽度；十一个页面逐页检查无横向滚动条。
  - [ ] AC2 窄屏下侧栏默认收起，顶栏按钮与「更多」标签都能打开抽屉；抽屉内含最近对话列表、搜索、新建对话、伙伴、提醒、技能、记忆、模型接入、通知通道、个人资料、主题与退出登录；点遮罩或按返回键关闭。
  - [ ] AC3 窄屏下底部常驻五项标签栏，当前页高亮；「更多」按钮已打开抽屉时不再叠加打开。
  - [ ] AC4 聊天页头部在窄屏下只保留伙伴名与必要按钮，模型绑定与思维链开关收进可展开面板，两者功能与桌面一致（切换伙伴、切换会话模型、切换思维链显示都生效）。
  - [ ] AC5 输入区在软键盘弹出时保持可见（不被键盘遮住），`textarea` 与发送按钮可点；发送按钮与输入框高度不小于 40 像素。
  - [ ] AC6 窄屏下附件入口有两项：「相册 / 文件」打开系统选择器，「拍照」带 `capture="environment"` 直接进相机；桌面仍是单个入口。拍照得到的图片走同一条缩放与转码链路，仍受「模型不支持图片识别」的拦截与提示约束。
  - [ ] AC7 打开一个超过 200 条事件的会话，首次请求只取最近 50 条；向上滚动到顶部后自动取更早的 50 条并保持当前阅读位置不跳动；`GET .../events` 不带参数时返回全部事件（桌面端与既有测试行为不变）。
  - [ ] AC8 用另一个账号登录后请求他人会话的 `/events` 返回 404，且响应正文不含任何事件内容；本人会话照常返回。
  - [ ] AC9 窄屏下今天 / 盘面 / 成长三页的三列与四列卡片网格降为单列或两列，分类切换条四项在一行内可点，明细不出现横向滚动条。
  - [ ] AC10 `GET /manifest.webmanifest` 返回 200 且 `Content-Type` 为 `application/manifest+json`；`GET /icon-192.png` 与 `GET /icon-512.png` 返回 200 且 `Content-Type` 为 `image/png`；页面 `<head>` 含 `theme-color` 与 `apple-touch-icon`。安卓自带浏览器「添加到主屏幕」后图标与名称正确。
  - [ ] AC11 带 `Accept-Encoding: gzip` 请求 `/assets/<哈希>.js` 时响应含 `Content-Encoding: gzip`、`Vary: Accept-Encoding` 与长缓存头；不带该头时返回未压缩正文；`/` 与 `/index.html` 响应含 `Cache-Control: no-cache`。
  - [ ] AC12 以 390×844 视口在真实浏览器里走通一遍：登录 → 打开对话 → 发一张图片 → 点击缩略图看大图 → 滚到顶触发续取 → 切到盘面页 → 打开抽屉 → 切换伙伴 → 退出登录，全程无控制台报错。
  - [ ] AC13 `pnpm test` 全绿、`pnpm typecheck` 与 `pnpm --dir web typecheck` 零错误、`pnpm build:web` 成功。
  - [ ] AC14 `docs/deployment.md` 写明：监听地址与端口的环境变量、防火墙放行 8787、路由器端口映射步骤、手机接入步骤、备份与升级命令，以及明文 HTTP 下的风险说明与可选硬化（反向代理 + 证书、限制注册入口、收紧登录限速）。

## 2. Research Findings

### 2.1 三层使用的技术（现状事实）

| 层 | 目录 | 使用的技术 | 依据 |
|---|---|---|---|
| 核心库 | `src/harness/` | 纯 TypeScript，零运行时依赖，零平台接口（平台能力经 `PlatformEnv` / `FileIO` / `SessionLog` 注入） | `package.json` 无 `dependencies`；`src/harness/env.ts` |
| 应用层 | `src/app/` | Node ≥ 22.13（内置 `node:sqlite`、`node:http`、`node:crypto`）、`tsx` 直接运行 TypeScript、无 Web 框架 | `src/app/main.ts`、`src/app/server.ts`、`src/app/db.ts` |
| 前端 | `web/` | React 18.3 + Vite 6 + Tailwind 3.4（postcss + autoprefixer）、react-markdown 10（GFM + 单换行）、零路由库（视图状态在 `App.tsx` 内） | `web/package.json`、`web/src/App.tsx:39` |
| 测试 | `test/` | vitest 3，模拟适配器，时钟与随机全注入 | `package.json`、`test/` |

数据形态：SQLite（WAL + `synchronous=FULL`），密钥走 AES-256-GCM 密封（`data/secret.key`），会话令牌存 `sessions` 表，Cookie 属性为 `HttpOnly; Path=/; SameSite=Lax`，有效期 30 天。

### 2.2 移动端适配现状：几乎没有

- 全部前端源码里，Tailwind 断点前缀只出现两次（`Chat.tsx:306` 的 `sm:flex`、`Settings.tsx:488` 的 `sm:grid-cols-2`）。
- 根容器是 `flex h-screen overflow-hidden`（`App.tsx:134`），侧栏是 `w-60`（240 像素）且不可收起；按 375 像素宽计算，内容区只剩约 135 像素，聊天基本不可用。
- `index.html` 已有正确的 viewport 声明，触屏点击目标（导航项 40 像素、发送按钮 40 像素）本身达标。
- 没有 `@media` 规则、没有安全区内边距、没有 `dvh` 单位、没有 `touch-action` 调整、仓库里没有任何图标文件（`web/public/` 为空），也没有站点清单。
- 内容页统一用 `mx-auto max-w-2xl px-4 py-6` 包裹，窄屏下这些页面的外层留白本身就合适，真正需要改的是固定列数网格、聊天页与侧栏。

### 2.3 长对话的传输与渲染代价

- `GET /api/conversations/:cid/events` 一次返回该会话全部事件（`server.ts:466`），事件正文里的图片是 base64 内嵌在 `event_json` 中，没有任何分页参数。
- 前端 `foldEvents` 把事件折叠成气泡，工具调用与结果靠 `event.id` 配对；分段取回时若片段里只有结果没有调用，折叠会漏画一条回执，属于可接受的降级。
- 静态托管没有任何压缩与缓存头（`server.ts:150` 只写 `Content-Type`），当前构建产物 `index-Fi67Mbhv.js` 为 444 412 字节、`index-jtk63s_H.css` 为 21 310 字节，手机上每次刷新都全量重传。

### 2.4 越权读取（本次一并修复）

- `server.ts:465-470` 按 `cid` 直接查 `conversation_events`，没有校验该会话属于当前登录用户；`conversation_events` 表本身不含 `uid` 列，归属信息只在 `conversations` 表。
- 同一文件里的其它会话子路由（`meta` / `agent` / `model` / `messages`）都经 `ConversationStore` 的 `AND uid = ?` 查询，只有 `events` 这一条绕过了。
- 触发条件：任意注册用户拿到他人 `cid` 即可读取全部聊天记录与图片。cid 是 `randomUUID`，猜不到，但公网开放端口后会话 id 可能经浏览历史、截图、共享链接等途径外流。

### 2.5 风险与不确定项

- **明文 HTTP 是本次最大的风险**：登录口令、会话 Cookie、全部聊天内容与 API Key 在网络上以明文传输。README 的既有建议是「公网暴露前请确认已经配好反向代理与 HTTPS」，本次按用户决定不配证书，该差异记录在此，不写成代码里的强制拦截。
- 手机自带浏览器的内核版本不可控，`dvh`、`env(safe-area-inset-*)`、`createImageBitmap`、`canvas.toDataURL("image/webp")` 的可用性需要实机确认；降级路径分别是 `h-screen` 兜底、零内边距、`Image` 元素加载、按 Data URL 实际类型回读（这条链路已实现）。
- 底部标签栏与软键盘叠加：安卓自带浏览器弹出键盘时可能压缩视口，输入区需要保持在可视区内，实机确认后再决定是否额外滚动定位。
- 桌面端行为不能回退：事件接口不带参数时必须保持全量返回，`foldEvents` 的调用签名与既有测试都要兼容。

## 3. Innovate (Optional: Options & Decision)

### Option A 窄屏布局：抽屉 + 底部标签栏，一套组件两种呈现

- 侧栏内容抽成一个组件，宽屏下作为固定栏渲染，窄屏下渲染为抽屉（遮罩 + 滑入面板 + 关闭按钮）。
- 底部标签栏与顶栏只在窄屏渲染。
- Pros: 桌面端零回归；导航项与内容复用同一份状态；窄屏下主要入口一次点击可达。
- Cons: 需要区分两套呈现，组件内部有条件分支。

### Option B 窄屏布局：只把侧栏改成抽屉

- 顶栏放菜单按钮，点开抽屉选任意页面。
- Pros: 改动集中，验证面小。
- Cons: 每次切页两次点击；窄屏下没有常驻的页面入口。

### Decision

- Selected: Option A
- Why: 用户选定「底部标签栏五项 + 侧栏改抽屉」；频繁使用的对话 / 今天 / 盘面 / 成长四项一次点击可达，低频设置项留在抽屉里，符合手机上单手操作的路径长度。
- 附：分段加载选择「按事件条数」，因为事件正文与图片在同一条记录里，按条数分段让正文与图片一起到达、共用一个游标，不需要两条取数链路再合并顺序。

## 4. Plan (Contract)

### 4.1 File Changes

服务端（`src/app/`）：

- `src/app/conversations.ts`：新增 `ownerOf(cid: string): string | undefined`（查 `conversations.uid`）与 `readEvents(cid: string, options?: { before?: number; limit?: number }): SessionEvent[]`（`ORDER BY seq DESC LIMIT ?` 取回后反转成升序；不带参数时保持全量升序）。
- `src/app/server.ts`：
  - `/events` 路由改为「先校验归属（`ownerOf(cid) === uid`，否则 404），再解析 `before` 与 `limit` 查询参数（非法值 400），再取事件」。
  - `serveStatic` 增加压缩与缓存头：`/assets/` 前缀的资源带 `Cache-Control: public, max-age=31536000, immutable`；`.html` 与无扩展名回退带 `Cache-Control: no-cache`；请求头含 `gzip` 且类型为文本类（`.js`、`.css`、`.html`、`.json`、`.svg`、`.map`、`.txt`）时用 `node:zlib` 的 `gzipSync` 压缩并写 `Content-Encoding: gzip` 与 `Vary: Accept-Encoding`。
  - `CONTENT_TYPES` 增加 `.webmanifest` 与 `.png` 已有项的对齐（`.png` 已在表内）。
