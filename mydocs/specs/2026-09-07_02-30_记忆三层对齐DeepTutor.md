## 用户诉求与裁决

1. 用户：现在的记忆"L1 然后马上就 L3"，中间没有 L2；要效仿 DeepTutor 的三层组织。
2. 现状根因：`memory.consolidate()` 把 collectSessionTexts 的 40 条原始对话一次 LLM 抽成 L3 四槽——**没有 L2 层**；L3 的判断没有证据链。
3. DeepTutor 参考结论（调研报告 2026-09-07）：
   - L1 = 工作区实时镜像（live 适配器扫描 + fingerprint diff + Refresh 落 changes）
   - L2 = 每 surface 事实文档（consolidator 从 L1 新实体抽取，entry 带 section+refs，seen_refs 增量门控，支持 更新/检查/去除）
   - L3 = 每 slot 综合文档（只吃 L2 新 entry，refs=裸 surface 名，slot=recent/profile/scope/preferences，preferences 永不自动综合）
   - 注入对话只有 L3；L1/L2 不进 prompt。
4. 本次裁决（自动决策，用户授权全程自动）：结构照搬 DeepTutor 三层；触发采用**自动链**（手动按钮/启动惰性 → L1 refresh → L2 update → L3 update），比 DeepTutor 的纯手动更省事，同时保留每层手动入口；记忆图谱、audit/dedup LLM 模式、多轮切块本次不做（记后续）。

## 领域建模（SQLite 新 5 表，DDL 进 db.ts）

```sql
CREATE TABLE IF NOT EXISTS l1_entities (
  uid TEXT NOT NULL, surface TEXT NOT NULL, ref TEXT NOT NULL,
  label TEXT NOT NULL DEFAULT '', ts INTEGER NOT NULL DEFAULT 0,
  fingerprint TEXT NOT NULL DEFAULT '',
  PRIMARY KEY (uid, surface, ref)
);
CREATE INDEX IF NOT EXISTS idx_l1_surface ON l1_entities(uid, surface);

CREATE TABLE IF NOT EXISTS l1_changes (
  uid TEXT NOT NULL, surface TEXT NOT NULL,
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  kind TEXT NOT NULL CHECK (kind IN ('added','modified','removed')),
  ref TEXT NOT NULL, label TEXT NOT NULL DEFAULT '', ts INTEGER NOT NULL
);

CREATE TABLE IF NOT EXISTS l2_entries (
  uid TEXT NOT NULL, surface TEXT NOT NULL, id TEXT NOT NULL,
  section TEXT NOT NULL DEFAULT '', text TEXT NOT NULL,
  refs_json TEXT NOT NULL DEFAULT '[]',
  created_ts INTEGER NOT NULL, updated_ts INTEGER,
  PRIMARY KEY (uid, surface, id)
);
CREATE INDEX IF NOT EXISTS idx_l2_surface ON l2_entries(uid, surface, created_ts);

CREATE TABLE IF NOT EXISTS l2_meta (
  uid TEXT NOT NULL, surface TEXT NOT NULL,
  seen_refs_json TEXT NOT NULL DEFAULT '[]',
  last_update_ts INTEGER,
  PRIMARY KEY (uid, surface)
);

CREATE TABLE IF NOT EXISTS l3_meta (
  uid TEXT NOT NULL, slot TEXT NOT NULL,
  seen_json TEXT NOT NULL DEFAULT '[]',   -- 已消费的 L2 entry ref："surface:id"
  last_update_ts INTEGER,
  PRIMARY KEY (uid, slot)
);
```

- L1 实体来源（live 适配器，不另存原始内容；内容按 ref 现查）：
  - `chat`：每会话一实体，ref=`chat:<cid>`，label=会话标题，content=该会话 user/assistant 文本按序拼接（尾部截断 6000 字），fingerprint=sha1(content)。
  - `ledger`：每条记录一实体，ref=`ledger:<seq>`，label=category/note 摘要，content=格式化行（时间/kind/分类/备注/数值），含 void 语义（作废记录不作为实体输出）。
  - `tasks`：每任务一实体，ref=`task:<id>`，content=标题+指令+trigger 摘要+启停+最近一次运行状态。
- L3 继续用 `memory_slots`（recent/profile/scope/preferences）存文档，`l3_meta` 记增量；`preferences` 不参与自动综合（save_preference 工具直写，与 DeepTutor 一致）。

## 模块与签名

新增 `src/app/memory-layers.ts`：

```ts
export const L1_SURFACES = ["chat", "ledger", "tasks"] as const;
export type L1Surface = (typeof L1_SURFACES)[number];
export const L2_SECTIONS: Record<L1Surface, string[]> = {
  chat: ["话题", "习惯", "误解", "掌握"],
  ledger: ["消费", "饮食", "健康", "作息"],
  tasks: ["坚持中", "常错过", "意愿"],
};
export const L3_SLOTS = ["recent", "profile", "scope"] as const; // preferences 不自动综合

export interface L1Entity { ref: string; label: string; ts: number; content: string; fingerprint: string }
export interface MemoryLayerDeps { db; now(): number; randomUUID(): string;
  chatEntity(uid, cid): L1Entity | null;            // 由 conversations 提供
  listConversations(uid): { cid, title, createdTs }[];
  ledgerRecords(uid): LedgerRecord[];               // ledgerFor(uid).readAll()
  tasks(uid): TaskDef[]; taskRuns(uid, id): TaskRun[];
}
export class MemoryLayers {
  l1Live(uid, surface): L1Entity[]                               // live 扫描
  l1Pending(uid, surface): { added; modified; removed }          // 对 l1_entities 的 diff 预览
  l1Refresh(uid, surface): { added; modified; removed }          // 落 l1_entities + l1_changes
  l1Changes(uid, surface, limit): ChangeRow[]
  l2Update(uid, surface, adapter, model): { added: number; skipped?: "no_new_input" | "model_error" }
  l2Entries(uid, surface): L2Entry[]
  l2EditEntry(uid, surface, id, patch): void; l2RemoveEntry(...): void
  l3Update(uid, slot, adapter, model): { changed: boolean; skipped?: "no_new_input" }
  runAll(uid, adapter, model): PipelineSummary                   // 全链：L1 refresh ×3 → L2 update ×3 → L3 update ×3
}
```

- `l2Update`：新实体（ref ∉ l2_meta.seen_refs）按时间线渲染 → 尾部截断 15000 字 → 单次 LLM 调用（prompt 见 `buildL2Prompt`：输出唯一 JSON `{facts:[{text≤240字, section∈目录, refs:[本块实体 ref]}]}`，禁绝对化表述，附已有条目防重复）→ 校验（section/ref 白名单，无 ref 丢弃）→ 插入 `l2_entries` → meta 落全部当前 refs。解析失败 fail-safe 不写。
- `l3Update`：新 L2 entry（`surface:id` ∉ l3_meta.seen_json）按 surface 分组渲染（不带 entry id，只带文本+section）→ 单次 LLM → 输出槽 markdown，证据脚注 `[^n]: <surface>`（对冲表述：判断必须带"在 N 次 chat 对话中"式依据）→ `memory_slots.writeSlot` + l3_meta。空输入返回 no_new_input。
- 注入不变：`MemoryStore.injectionBlockSync` 依旧注入 L3 四槽并剥脚注（stripFootnotes 已兼容 `[^n]:` 行）。
