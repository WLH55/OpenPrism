国庆假期第一天，先问三个扎心的问题：

你手机里是不是躺着记账、打卡、待办、日记……四五个 App，每个都只用了三天？

你是不是也记过半个月账，某天一忙忘了记，看着断掉的记录从此摆烂？

你是不是跟某个 AI 聊得很好，三天后再来，它把你忘得一干二净？

我全中。所以我动手写了一个：**OpenPrism**，一个开源的 AI 生活助理。

一句话介绍：**聊天里说的每一笔花销、每一次运动、每一个心情，它都记进一本只追加的账本；该做的事到点由它来找你；三周前你说过的话，它真的记得。** 而它就住在你的微信里，不用再多打开一个 App。

全部代码开源，MIT 协议，GitHub 上每一行都摆着。下面说人话，讲讲它凭什么值得你花三分钟。

## 01｜聊天就是记录，一句话的成本

不用填表单，不用选分类。说一句「午饭 35」「跑步 40 分钟」「今天有点丧」，就记上了。

记错了？说一声「刚才那笔记错了」，它当场作废重记，每次修改都留痕可查。

你自己试试就知道：一句话的成本，比打开任何一个记账 App 都低。**记录这件事失败的根本原因从来不是懒，是每次都太贵了。**

## 02｜它不住在 App 里，它住在你的微信里

这是我做它最重要的一个决定。

大多数 AI 应用死于「懒得再打开一个软件」——明明微信一开就是一整天。

所以 OpenPrism 支持扫码绑定微信（腾讯官方机器人接口）：绑定之后，它就是你微信里的一个「好友」。想记一笔、想聊两句，微信里直接说；它的回复你直接在聊天列表里看；你在网页端和微信端两边聊，记录都不丢。

像一个会记事、会催你、还记得你的朋友，安静地躺在你的好友列表里。

## 03｜到点来找你的，不是闹钟，是「伙伴本人」

注册第一天，它自动帮你建好三个定时任务：

- **每天 8:30，一份简报**：今天的计划、该做的事；
- **每天 20:00，一声问候**：今天怎么样？漏的卡现在补还来得及；
- **每周日 21:00，一份周复盘**：这周完成了什么、差了什么、下周聚焦哪件。

关键区别在于：到点不是系统给你推一条冷冰冰的模板文案，而是**你的伙伴本人「醒来」**——它去读你的账本，看你这周到底做了什么，然后说人话。你回复它，它接着上下文继续聊。

更常用的是自定义：「每晚 23 点提醒我睡觉」「下个月 1 号提醒交房租」——对话里随口说一句，它就帮你建好。单次、周期都行。

## 04｜习惯这件事，终于不用全靠意志力

「每周跑 3 次」「每天读书半小时」——定个配额，它按周帮你计数。

跑了 2/3，晚上它来提醒你差的那一次；打卡支持补历史卡（之前做了忘了打？选日期补上）和撤销（手滑点错？作废重打，留痕可审计）。

连续天数、完成率、周环比、30 天热力图全自动生成。你的每一次坚持，都看得见。

> 📷 此处插入：docs/screenshots/today.png（今天页：打卡与进度）

## 05｜它真的记得你——但记什么，你说了算

三周前你提过乳糖不耐，今天它就不会给你推荐奶茶。

你的偏好、习惯、在意的事，会在聊天中沉淀成它的**长期记忆**，跨会话生效。

更重要的是：记忆页里每一条都摊开给你——可看、可改、可删、可导出。**它记得你，但你说了算。** 这是我能想到的、人和 AI 相处最舒服的姿势。

## 06｜你的数据，看得见、带得走

这一节给所有被「黑盒服务」伤过的人：

- **面板全自动**：你记过什么分类，它就长出什么维度的折线趋势、热力图、月度明细——不烧一个 token，全部从账本确定性算出；
- **模型 Key 属于你自己**：接入 DeepSeek、GLM、Qwen、Moonshot、OpenRouter 或任何 OpenAI 兼容端点，Key 以 AES-256 加密落盘，明文永不回传；
- **数据是一个文件**：所有记录都在一个 SQLite 文件里，一句命令备份，拷走就是整体迁移，不绑架、不锁定；
- **想彻底归自己？** 整套开源，一台自己的电脑就能跑起来，四行命令：

```
git clone https://github.com/WLH55/OpenPrism.git
cd OpenPrism && pnpm install
pnpm build:web
pnpm start
```

## 最后，说点实在的

这是我的个人项目，不完美，但足够透明：代码全开源（GitHub 搜 **OpenPrism**），架构站在 WeKnora（腾讯微信团队开源）和 dsh 两个开源项目的肩膀上，致谢写在 README 第一屏。

两个明人不说暗话的提示：

1. **AI 能力需要你自己的模型 Key**（注册后在「模型接入」页填入，DeepSeek 充十块钱能用很久）；
2. **我搭了一个在线体验站**：https://openprism.dpdns.org ——小水管服务器，注册有上限，满员的话代码就在下面，自部署才是完全体。

GitHub：**https://github.com/WLH55/OpenPrism** （MIT 协议，欢迎 Star，欢迎 Issue）

自律不难，难的是没人陪你。现在，有了一个会记住你、会督促你、说到点就来的朋友。

假期快乐，也假期别太放纵——毕竟今年只剩 92 天了，你的伙伴都帮你数着呢。
