# 部署指南（服务器 + 手机使用）

> 面向场景：把 OpenPrism 跑在一台长期开机的服务器或家用电脑上，用手机浏览器访问使用。
> 本机、局域网、公网共用同一份代码，靠环境变量与网络配置区分形态。

## 环境要求与启动

- **Node.js ≥ 22.13**（应用层使用内置 `node:sqlite`）、**pnpm**
- 构建前端并启动：

```bash
pnpm install
pnpm build:web     # 产物 web/dist，应用层启动时静态托管
pnpm start
```

环境变量：

| 变量 | 默认值 | 说明 |
|---|---|---|
| `OP_PORT` | `8787` | HTTP 监听端口 |
| `OP_DATA` | `./data` | 数据目录；主密钥 `secret.key` 落在这里 |
| `OP_DB` | `{OP_DATA}/openprism.db` | SQLite 数据库文件路径 |
| `OP_MAX_USERS` | `50` | 注册用户数上限；达到后新注册返回 403（提示自部署或联系站长）。自部署放开注册设 `0` |

服务监听 `0.0.0.0`，同网段任何设备都能访问。长期运行建议配进程守护（`pm2 start "pnpm start" --name openprism`）或系统服务；改应用层代码后需要重启，前端改动重新 `pnpm build:web` 后刷新页面即可。

## 手机接入（同一 Wi-Fi）

1. 查服务器的局域网地址：Windows 用 `ipconfig` 看「IPv4 地址」，Linux 用 `ip addr`。
2. 手机浏览器打开 `http://<服务器局域网地址>:8787`，注册账号即可使用。
3. 浏览器菜单里「添加到主屏幕」：出现 OpenPrism 图标，点击直达（页面仍由浏览器加载）。

窄屏（小于 768 像素）界面自动切换：

- 底部常驻五项标签栏：对话 / 今天 / 盘面 / 成长 / 更多；「更多」与顶栏菜单按钮都打开抽屉。
- 抽屉里是完整侧栏：最近对话（可搜索、可新建、可删除）、伙伴、提醒与全部设置项；安卓返回键可以收起抽屉。
- 聊天页头部的模型绑定、思维链开关、切换伙伴收进「会话设置」面板（头部的滑杆按钮）。
- 上传入口分两个：「图片 / 文件」走系统选择器，「拍照」直入后置相机。
- 长对话分段加载：打开只取最近 50 条事件，滚动到顶部自动续取更早 50 条，阅读位置不跳动。

## 公网开放（路由器端口映射）——先读风险

**明文 HTTP 的风险，开放端口前务必了解：**

- 登录口令、会话 Cookie、全部聊天内容与图片在网络上**不加密**，链路上的任何一方（Wi-Fi 提供者、运营商、中间设备）都能截获。
- 注册入口开放：任何拿到地址的人都能注册账号成为用户（注册与登录有每 IP+用户名每分钟 10 次的限速，会话事件接口已按归属校验，跨用户读取会得到 404）。
- 浏览器对 `http://` 来源不提供安全上下文：「安装应用」「离线缓存」不会生效，可用的只有主屏幕快捷方式。
- 会话 Cookie 没有设 `Secure` 属性：明文 HTTP 下设置它会导致浏览器拒绝回传 Cookie、登录直接失效。

**映射步骤**（外部 8787 → 服务器 8787）：

1. 服务器防火墙放行入站 TCP 8787（Windows 防火墙「入站规则」新建端口规则；Linux `ufw allow 8787/tcp`）。
2. 路由器管理页（通常 `http://192.168.1.1`）找到「端口转发 / 虚拟服务器」，外部端口 8787 → 服务器内网 IP 的 8787。
3. 手机关掉 Wi-Fi 用移动数据，访问 `http://<公网IP>:8787`（公网 IP 搜索「我的 IP」可得）验证连通。

**建议的加固路径（按代价从低到高）：**

- **Tailscale / WireGuard 加密隧道**：手机与服务器加入同一虚拟内网，不开放任何公网端口，传输全程加密，任何网络下都能访问。
- **反向代理 + HTTPS**：有域名时用 Caddy（自动申请续期证书）或 Nginx + certbot 挂在 8787 前面；此时浏览器获得安全上下文，主屏幕快捷方式自动升级为完整安装（独立窗口、离线缓存生效）。
- 口令用长随机串；定期备份；不再使用时关掉端口映射。

## 备份与升级

```bash
# 备份：WAL 模式下不要裸拷数据库文件，用 VACUUM INTO
sqlite3 data/openprism.db "VACUUM INTO 'backup-$(date +%F).db'"

# 升级
git pull
pnpm install
pnpm build:web
pm2 restart openprism   # 或按你的守护方式重启
```

数据全在 `OP_DB` 指向的单个 SQLite 文件里，连同 `data/secret.key`（主密钥，丢了它密封的 API Key 无法解开）一起拷走即完成整体迁移。

## 图标重生成（维护）

图标源文件是 `web/public/icon.svg` 与 `web/public/icon-maskable.svg`（Prism 图形）。改动后重新生成各尺寸 PNG：

```bash
pnpm add -D sharp        # 首次
node e2e-data/make-icons.mjs
pnpm build:web
```
