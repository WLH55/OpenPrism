# 多用户与自部署形态：登录注册第一批进主干

OpenPrism 从"自用优先的单人工具"升级为可自部署的多用户产品：公网多租户、本机、局域网三种部署共用同一核心（harness 为零平台依赖纯 TS 库，服务器/本地同构），个人自用即自部署的最小形态。登录注册与按用户隔离（`users/{uid}/` 完整沙盒：账本 + 会话 + 记忆 + 智能体配置）属**核心必做需求**、随首版主干实现——不做"先单人后加层"，也不作为后续升级项。本 ADR 修订 [ADR 0001](0001-self-use-first-open-source-grade.md)：自用仍是第一用户与验收方式，但不再是产品边界。存储裁决随附：账本事件模型引擎无关（只追加 + 折叠 + 更正回路），单机/局域网每用户一本 JSONL，云端多租户在运维需要时以数据库为存储引擎（append-only 表），真相层与折叠层不动（FileIO 缝）；否决日志与数据库并立的双真源（2026-08 D3.2 伤疤）。
