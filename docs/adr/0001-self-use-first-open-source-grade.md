# 0001 自用优先，按开源标准架构

OpenPrism 近期目标是作者自用，但架构决策一律按"将来可开源给别人用"的标准执行：插件边界、事件模型、数据导出能力不做"仅适合个人硬编码"的捷径。代价是比纯自用慢；换来的是避免日后"个人脚本改造为产品"的高昂返工——竞品调研（2026-08）显示，本地优先与数据可导出是此类产品的信任入场券，晚改造不如早设计。

## Considered Options

- **直接冲开源产品**：第一天就配齐 onboarding、示例数据、文档、面板可配置——工程量大，且在缺乏真实自用验证前做通用性是在猜需求。
- **纯自用工具**：维度 schema 全部硬编码——最快见效，但基本堵死开源转化路径。
