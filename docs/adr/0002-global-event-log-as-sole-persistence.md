# 0002 全局事件日志是唯一持久层，会话日志只作凭据

OpenPrism 的结构化数据只有一个存储：append-only 的全局事件日志，面板/周报/工具查询一律从它全量折叠进内存（个人量级毫秒级）；dsh storage-domain 的四张表整体废弃。会话日志只携带标准 `tool/call`/`tool/result`（dsh 对事件类型有运行时白名单，未知事件会被拒绝加载，第三方无法注册），**录入凭据即会话里的工具调用**；openprism_* 事件由镜像器订阅 `session/event` 抽取进全局日志。事件带来源（`mirror` 会话镜像 / `ui` 面板操作 / `internal` 工具内部副作用），rebuild 只重放会话、原样保留非镜像事件。代价：插件自管日志的追加与折叠、按单实例假设设计；换来单一真源（无双写漂移）、可随时重建、「一个文件就是全部数据」的可导出性。

## Considered Options

- **storage-domain 四张表为真源（v0.3 现状）**：工具直写表、镜像仅作审计——双真源必然漂移，可重建承诺落空。
- **表降级为持久缓存（物化视图）**：查询最快，但双份存储 + 增量失效逻辑，当前数据量用不到，属过早优化。

## Consequences

- 「唯一持久层」指面板数据：always-record 的采集原料存独立的按月分片采集日志，可按保留策略整月裁剪（→ ADR 0003）。
