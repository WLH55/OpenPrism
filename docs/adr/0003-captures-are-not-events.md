# 0003 采集原料独立于全局事件日志

always-record 的采集原料（对话原文等）存独立的按月分片 append-only 采集日志，提炼产出的结构化事件才进全局事件日志并回链 `captureId`；原料按保留策略整月裁剪（如提炼后 30 天）。ADR 0002 的「唯一持久层」指面板数据而言——原料不是面板数据，不参与折叠，且需要独立于事件历史的删除能力（隐私与体积）；混入主日志与仅追加冲突。

## Considered Options

- **原料作为事件混入全局日志**：单存储最简，但面板折叠需过滤原料、裁剪即改写日志，与仅追加冲突。
- **不落盘原料、实时处理完即丢**：管线故障即丢原料，放弃「先落库再并行处理」的可靠性初衷。
